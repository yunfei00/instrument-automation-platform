# Instrument Profiles

Instrument Profile 用于描述某个仪表家族/型号相关的结构化工程知识，例如：

- manufacturer
- model / family
- firmware
- installed options
- channel / frequency range / bandwidth
- capabilities
- driver mapping
- command catalog
- manual registry
- qualification status
- engineering notes

Profile 是“原厂资料 + 实机验证”沉淀后的知识入口，不应保存公司/客户的敏感唯一设备信息。
