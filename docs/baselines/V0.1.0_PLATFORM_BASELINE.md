# Instrument Automation Platform v0.1.0 基线

## 目的

`v0.1.0-platform-baseline` 建立了个人仪表自动化与工程知识平台的第一套稳定架构。

该基线刻意聚焦**可复用单仪表能力**，不是业务应用版本。

## 已包含的架构

### Core

- Transport 抽象
- VISA Transport
- Mock Transport
- SCPI Client
- IEEE 488.2 Helpers
- 通用 Error Model
- Capability Model
- `InstrumentDriver` Contract
- Driver Registry

### 工程基础设施

- 原厂 Manual Registry
- Structured Command Catalog
- Command Verification Status
- Instrument Lab
- Command Probe
- 自动文档生成
- Record / Replay
- Qualification Framework

### Driver 生命周期

```text
experimental
  -> qualified
  -> supported
  -> deprecated
```

## 参考仪表 1：Keysight DSO-X 3000 X-Series

初始目标：`DSO-X 3034A`。

v0.1.0 基线已覆盖：

- identity
- channel
- timebase
- trigger
- acquisition
- measurement
- waveform metadata
- binary waveform acquisition
- waveform conversion
- hardware probe
- qualification requirements

## 参考仪表 2：Rohde & Schwarz FSW

v0.1.0 基线已覆盖：

- identity
- center/span/start/stop frequency
- RBW / VBW
- trigger
- initiate
- trace format
- trace acquisition
- marker command knowledge
- system error
- hardware probe
- qualification requirements

当时部分 FSW 命令仍为 `candidate`，必须通过手册或实机证据后才能提升。

## 仓库边界

允许：

- 可复用仪表行为
- 仪表知识
- Driver
- Transport / Protocol
- Test Infrastructure
- Qualification
- Replay
- Documentation

不允许：

- 联合采集产品
- 多仪表业务编排
- 客户专用 Workflow
- 产品业务 UI
- 应用专用报告
- 客户专用数据模型

## 基线规则

后续新增仪表必须优先扩展本基线，而不是重新建设通信基础设施。

典型后续对象：

- Keysight N9020A
- Siglent SDS3000X HD
- R&S CMW500
- Signal Generator
- Power Supply
- 其他 SCPI/VISA 仪表
