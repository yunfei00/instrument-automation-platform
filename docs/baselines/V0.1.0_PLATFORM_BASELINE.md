# Instrument Automation Platform v0.1.0 Baseline

## Purpose

This baseline establishes the first stable architecture for the
personal instrument automation and engineering knowledge platform.

The repository is intentionally focused on reusable single-instrument
capabilities.

It is not an application repository.

## Architecture Included

### Core

- Transport abstraction
- VISA transport
- Mock transport
- SCPI client
- IEEE 488.2 helpers
- common error model
- capability model
- InstrumentDriver contract
- driver registry

### Engineering Infrastructure

- official manual registry
- structured command catalog
- command verification state
- Instrument Lab
- command probe
- generated documentation
- Record / Replay
- qualification framework

### Driver Lifecycle

- experimental
- qualified
- supported
- deprecated

## Repository Boundary

Allowed:

- reusable instrument behavior
- instrument knowledge
- drivers
- transport
- protocol
- test infrastructure
- qualification
- replay
- documentation

Not allowed:

- joint acquisition products
- multi-instrument business orchestration
- customer-specific workflow
- product UI
- application-specific reporting
- customer-specific data models

## Baseline Rule

Future instrument support should extend this baseline rather than
rebuild instrument communication infrastructure.

Examples:

- Keysight N9020A
- Siglent SDS3000X HD
- Rohde & Schwarz CMW500
- signal generators
- power supplies
- other SCPI/VISA instruments
